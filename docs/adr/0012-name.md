# ADR-0012: Language name and file extension

- **Status:** Accepted
- **Date:** 2026-11-14
- **Tier:** Light (see `docs/PROCESS.md`)
- **Decided by:** Claude (ruling R7). **John may veto by opening an issue; a name is his to overrule.**

## Context

The roadmap asks for 5 proposals, a pick, and John's veto. The criteria are:
- no clash with a known language or a big trademark in software;
- easy to say and type;
- a short, free file extension;
- a fit with what the language is for: code you can follow at 3 am (issue #5).

The checks were web searches on 2026-11-14.

## Options

| Name | Check | Verdict |
|---|---|---|
| Wren | A well-known scripting language by Bob Nystrom (https://wren.io/) | Taken |
| Kiln | An actively developed native language, "Kiln 2" (https://github.com/AxDSan/kiln/releases); the Kilns language (https://github.com/sellout/Kilns/wiki) | Taken |
| Tally | Tally Definition Language for the TallyPrime accounting product (https://help.tallysolutions.com/developer-reference/tally-definition-language/what-is-th-overall-perspective-on-tally-technology/) | Trademark risk |
| Brisk | Several hobby languages (https://github.com/spotandjake/Brisk, https://github.com/MavenRain/brisk) | Crowded |
| **Lantern** | Two small hobby repos (https://uithub.com/cococry/Lantern, https://gh.r-mj.com/DatAsianBoi123/lantern); unrelated software products also use the word | **Chosen** |

## Decision

- **Name:** **Lantern**. A lantern is what you carry at 3 am: the language is built so a tired reader can see where
  code is and what it does.
- **File extension:** `.ltn` (only obscure prior uses:
  https://www.file-extensions.org/extension/ltn).
- **Tool:** the binary is `lantern` (`lantern build`, `lantern test`, `lantern cover`, `lantern debug`,
  `lantern deps …`). `lang …` in earlier ADRs means `lantern …`.
- **Corpus:** the M0 corpus is renamed from `.p3` when it is copied into `tests/`. The design-phase examples keep
  `.p3`.

## Consequences

- **Cheap to change until M7 ships:** a rename is a search and replace.
- **Before any public release,** a trademark search by John or a lawyer is needed. This ADR only checked for clashes
  in the software ecosystem.
